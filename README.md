# Práctico: Base de Datos - Biblioteca

Repositorio con los ejercicios prácticos de modelado y consultas SQL para el sistema de gestión de una biblioteca.

## Contenido del Repositorio

* **`diagrams/`**: Modelos conceptuales y lógicos (MCD y DER) realizados en diagrams.net.
* **`scripts/`**: 
  * `01_esquema.sql`: Creación de tablas, restricciones y claves foráneas.
  * `02_datos_iniciales.sql`: Carga de autores, editoriales, libros, socios y préstamos iniciales.
  * `03_carga_empleados_y_operaciones.sql`: Inserción de empleados, especializaciones (atención y restauración), actualización de socios y nuevos préstamos.
